# Resurrección Digital

Proyecto académico basado en el reto:  
**"Hackeando el Futuro de una Pyme"**

---

## Descripción

Este proyecto representa la reconstrucción digital de una empresa dominicana que fue eliminada completamente de Internet tras un misterioso incidente.

El objetivo no fue solo recuperar la presencia digital, sino **reinventar la marca** con una identidad más fuerte, moderna y resistente.
